# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial version of Dify Swift SDK
- Support for all major Dify API endpoints
- Modern Swift async/await support
- Streaming response support
- Type-safe API interfaces
- Comprehensive error handling
- Support for iOS 13+, macOS 10.15+, tvOS 13+, watchOS 6+
- Zero external dependencies (Foundation and URLSession only)

### API Features
- **Base Client**: Message feedback, application parameters, file upload, text-to-audio, meta information
- **Completion API**: Create completion messages, streaming completion
- **Chat API**: Chat messages, streaming chat, conversation management, suggested questions, audio-to-text
- **Workflow API**: Run workflows, streaming workflows, workflow control

### Documentation
- Complete README documentation (English and Chinese)
- API reference documentation
- Usage examples and best practices
- Unit tests

### Development Tools
- Swift Package Manager support
- Comprehensive unit test suite
- Example code and usage guides
